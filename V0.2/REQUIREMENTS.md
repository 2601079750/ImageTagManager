# 第一版需求与约定

确认时间：2026-11-11。

- Windows 桌面应用，打包为可离线运行的 EXE，无账号。
- 多文件夹及多图片导入；文件夹默认包含子文件夹。
- 在系统“图片”目录中建立专用图片库。每次导入选择复制、移动或引用原位置；默认复制。保留源图文件名；目标重名时给新副本添加后缀以避免覆盖。
- 标签独立保存，不修改原图内容。标签属于可选分组，初始为画师、角色、场景、其他；图片可缺少任意分组，可关联多个同组标签。
- 支持新增标签、复用已有标签、批量添加和移除。当前图片更换标签与全局重命名标签是两个独立操作。暂不做标签合并。
- 多选标签，以全局交集或并集筛选；可与文件名/标签搜索叠加。
- 常见静态格式及动图；缩略图悬停轻微放大，动图角标和悬停播放；大图支持预览、缩放、拖动和动图播放。
- 排序为文件名、修改时间、图片分辨率、文件大小，分别支持升序/降序，额外提供导入时间。分辨率按像素总数比较。
- 启动检查、运行时自动同步、手动重新扫描。第一版运行时每 15 秒后台轮询。
- 内容指纹帮助恢复移动/改名后的图片，保留标签；唯一匹配自动恢复，多候选由用户选择，内容变化可手动重新关联。缺失记录及已有缩略图保留。
- 提供图片所在位置、来源目录重新定位、指定目录查找丢失图片。
- JSON 备份图片记录、标签及关联，不包含原图。恢复前验证并保存当前标签库；图片改路径后可重新关联。
- 第一版不含重复图片识别、联网、自动打标签、标签合并和复杂交并集混合表达式。

本项目内的测试与演示仅操作生成的图片；尚未导入用户的实际收藏。

## V0.2 增量需求（2026-11-12）

- 每次迭代放入独立版本目录，保留历史版本。
- 防止滚轮更改下拉栏选项。
- 缩略图悬停以平滑动画放大和缩小，选中标记抗锯齿，卡片圆角。
- 右侧按创建标签、已有标签框、可复用标签列表排序。
- 标签管理支持全局删除、批量移动分类；类别可自定义或删除，默认分类仅首次初始化。
- 提供白色、黑色、跟随系统主题并保存选择。
- 标签选中配色加强，适配浅色与深色主题。
- 设置界面集中管理外观、自动同步、备份与恢复，按页签组织以便扩展；主题及同步开关持久保存。
- 筛选下拉框仅显示“全部”“任一”，对应满足全部标签或至少一个标签。
